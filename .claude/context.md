# 이직 준비 자기계발 루틴 — 대화 컨텍스트

## 목표 및 배경

- **최종 목표**: 이직 (개발자)
- **부가 목표**: 헬스장 루틴 병행

---

## 개인 상황

| 항목 | 내용 |
|------|------|
| 출근 시간 | 오전 8시 ~ 10시 (유동적) |
| 퇴근 시간 | 오후 5시 ~ 7시 (유동적) |
| 출퇴근 시간 | 편도 1시간 (왕복 2시간) |
| 기상 시간 | 05:30 |

---

## 이직 준비 항목

- 포트폴리오 / 이력서 정리
- 기술 스터디 — Java, Spring, CS 지식
- 코딩 테스트 (코테) 준비
- 면접 준비 (기술 면접, 영어 면접)
- 네트워킹 / 정보 수집
- 토플 / 영어회화
- 사이드 프로젝트

---

## 헬스 루틴

- **헬스장 시간**: 유동적 (출근 시간에 따라 아침 배치)
- **헬스 구성**: 웜업 10분 → 메인 운동 40분 → 유산소 30분 → 쿨다운 + 스트레칭 10분 (총 약 90분)
- **헬스 요일 (8시 출근)**: 월, 화, 목, 금 (주 4일)
- **헬스 요일 (10시 출근)**: 월, 수, 목, 토 (주 4일)

## 플래너 앱 정보

- **형태**: 단일 HTML 파일 (`index.html`)
- **호스팅**: GitHub Pages 예정
- **기능 목록**:
  - 8시 / 10시 출근 탭 전환
  - 요일별 탭 전환
  - 헬스 요일 자동 표시 (🏋)
  - 오늘 달성률 진행 바
  - 주간 달성률 바 차트
  - 오늘 포커스 뱃지
  - 진행 중 / 다음 블록 자동 강조
  - 체크박스 — **로컬 스토리지 저장** (브라우저 재시작 후에도 유지)
  - 블록 추가 (시간 + 제목 입력)
  - 항목 추가 (내용 + 태그 선택)
  - 추가한 블록/항목 삭제
  - 인앱 토스트 알림 (🔔 버튼으로 활성화, 스케줄 시간마다 알림)
  - 아이폰 Safari / PWA 대응 (viewport-fit, safe-area)

## GitHub Pages 배포 방법

1. GitHub 저장소 생성 (Public)
2. `index.html` 업로드
3. Settings → Pages → Branch: main / root → Save
4. URL: `https://사용자명.github.io/저장소명`
5. 아이폰 Safari에서 열고 **공유 → 홈 화면에 추가** → 앱처럼 사용
